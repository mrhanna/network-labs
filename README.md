# Network Labs

At the end of the first interview I got after I finished my CCNA, one of the interviewers recommended that I get hip to [containerlab](https://containerlab.dev/). No doubt it's going to be a game-changer.

This repository is sandbox for networking experiments, primarily using containerlab. It started as a way to get hands-on with virtual network infrastructure and is growing into a place to document labs, experiments, and things I'm learning as I work through networking concepts. Some projects are quick exercises; others are more substantial investigations. The individual READMEs explain the goals, implementation, and any compromises or deviations involved.

## Featured Projects

### 05 - BGP Lab Notes

_BIRD · FRRouting · Linux · BGP_

A hands-on investigation of BGP route selection and traffic engineering based on [antonu17's lab](https://github.com/antonu17/lab-network-bgp), with detailed notes explaining the reasoning behind configuration and troubleshooting steps.

### 04 - JITL CCNA Mega (c)Lab

_Containerlab · Cisco IOS · Arista EOS · Linux · Ansible_

A containerlab recreation of Jeremy's IT Lab's CCNA Mega Lab, originally published in Cisco Packet Tracer. Includes a multi-device campus network and working Ansible automation, with implementation notes documenting where the containerlab environment differs from the original.
